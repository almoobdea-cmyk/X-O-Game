# سجلّ التحقق

## الجولة 1 — 2026-10-20

### أ. محرّك القراءة الصوتية (`scripts/reading.mjs`)

اختبارات وحدة بـ `node --test`: **28 من 28** ناجحة بعد أربع دورات إصلاح.

ما كُشف وأُصلح أثناء الجولة:

| العطل | المثال | الإصلاح |
|---|---|---|
| حروف المدّ تُسقط علامة الطول | كِتَابٌ → kitab | إعادة كتابة منطق الإطالة: يُستبدل الصائت القصير المنطوق بصيغته الطويلة |
| تنوين الفتح قبل الألف الساكنة لا يُعامَل معاملة آخر الكلمة | كِتَابًا عند الوقف → kitaban | تحديد «الحرف الأخير الفعلي» بتجاوز ألف التنوين والألف المقصورة |
| الألف الخنجرية تُهمل | هَـٰذَا → hadha | معالجة U+0670 قبل الحركة القصيرة |
| «الَّذِينَ» لا تُعرف أداةَ تعريف | → lladhin | قبول اللام المشدّدة في موضع لام التعريف |
| الهمزة في أوّل الكلمة تُكتب في النقل اللاتيني | إِلَى → ʾila | إسقاطها في أوّل الجذع (بعد أداة التعريف أيضًا) في النقل اللاتيني فقط |
| الكلمات ذات الألف غير المرسومة | هَذِهِ → hadhihi | جدول استثناءات (هذا، هذه، ذلك، لكن، الله، الرحمن، أولئك، عمرو، مائة…) مع دعم السوابق |
| سابقة الواو والفاء وحروف الجرّ قبل «ال» | وَالْأُمُّ → wālʾummu | عدّ السوابق (حتى اثنتين: وَبِالْـ) ثمّ إسقاط ألف الوصل |
| «وَاحِدٌ» تُحسب سابقةً + همزة وصل | → wa-ḥid | اشتراط أن يلي الألفَ لامُ تعريف أو ساكن |
| لام الجرّ مع «ال» المحذوفة ألفها | لِلطَّالِبِ، لِلَّهِ | استرجاع ألف افتراضية قبل التحليل |

ما بقي معروفًا ولم يُعالَج: التقاء تنوين الاسم بهمزة الوصل (مُحَمَّدٌ الْـ → muḥammaduni l-) يُقرأ بلا كسرة الوصل؛ الوقف على المشدّد يُنطق مضعّفًا دائمًا؛ لا معالجة للإدغام بين الكلمات (نون ساكنة أو تنوين في حروف يرملون) لأنّه من أحكام التجويد لا النطق المعياري.
