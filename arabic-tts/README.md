# ناطق — محرّك عربي مستقلّ من النصّ إلى الصوت

يقرأ النصّ العربي المشكّل صوتًا بالفصحى أو بالسعودية البيضاء، ويسجّل نبرة صوت المتكلّم ويعيد استخدامها، ولا يعتمد على أيّ نموذج أو خدمة خارجية أثناء التشغيل. JavaScript خالص بلا اعتماديات، يعمل في Node وفي المتصفح.

## ما الذي يحاكيه من ElevenLabs وما الذي لا يحاكيه

| في ElevenLabs | هنا |
|---|---|
| واجهة النصّ: لغة من النصّ، لهجة من الصوت، تشكيل يحسم النطق | المحرّك نفسه: قواعد المهارة `arabic-harakat-reading` (وصل، وقف، إدغام، أصوات اللهجة) ثمّ خطّة صوتية (مُدد، تضعيف، وقفات من الترقيم، نغمة الاستفهام والخبر) |
| استنساخ فوري من تسجيل قصير | **تسجيل النبرة**: 48 كلمة مسجّلة تُحلَّل إلى ملفّ متكلّم (طبقة الصوت ومداها، مقياس التردّدات الصيغية، السرعة) ووحدات صوتية مقطّعة بمحاذاة آلية |
| شبكة عصبية تولّد الموجة | **مركّب تردّدات صيغية** (طراز Klatt) للنطق الصحيح، و**تركيب بالوصل** من وحدات المتكلّم مع PSOLA للمدّة والطبقة. آليّ الطابع، لا يقارب طبيعية الشبكات العصبية |
| نماذج مدرَّبة على آلاف الساعات | لا بيانات ولا تدريب. الطريق إلى الطبيعية مع بقاء الاستقلال: تدريب نموذج صوتي خاص (F5-TTS أو ما يماثله) على تسجيلاتكم؛ انظر `docs/arabic-tts-architecture.md` المرحلة 2 |

## التشغيل

```bash
cd arabic-tts
npm test                                   # 10 اختبارات: التهجئة، المدد، التنغيم، المركّب، تتبّع الطبقة، PSOLA، المحاذاة، التسجيل، الوضع
node cli.mjs say "ذَهَبَ الطَّالِبُ إِلَى الْمَدْرَسَةِ صَبَاحًا. هَلْ رَأَيْتَهُ؟" --out out.wav
node cli.mjs say "وِشْ رَايِكْ نْرُوحْ السُّوقْ بُكْرَة؟" --mode saudi --f0 110 --out saudi.wav
node cli.mjs demo --n 5                    # جمل الاختبار الذهبية إلى out/
node cli.mjs script                        # نصّ التسجيل (48 كلمة)
node cli.mjs enroll --dir recordings/ --out voice.json --name "اسمي"
node cli.mjs say "..." --voice voice.json  # التركيب بصوتك
npm run build                              # صفحة المتصفح web/nataq.html
```

التسجيل: ملفّ WAV لكلّ كلمة باسم رقمها (`01.wav` … `48.wav`)، أو ملفّ واحد `all.wav` بالكلمات بالترتيب مع صمت واضح بينها فيُقطَّع تلقائيًا. أيّ معدّل عيّنات؛ يُحوَّل إلى 16 كيلوهرتز.

## البنية

```
src/phonemize.mjs   نصّ مشكّل → أصوات + مُدد + منحنى طبقة (يستدعي محرّك القراءة في المهارة)
src/formant.mjs     جدول التردّدات الصيغية للأصوات العربية + مركّب متسلسل بمصدر حنجري وضجيج احتكاكي
src/voice.mjs       التسجيل: ميزات الإطارات، محاذاة برمجة ديناميكية، تقطيع الوحدات، ملفّ المتكلّم، حفظ/تحميل
src/concat.mjs      اختيار الوحدات بالسياق + PSOLA + وصل بتلاشٍ متقاطع، ورجوع إلى المركّب للأصوات الناقصة
src/dsp.mjs         تتبّع الطبقة (YIN)، طاقة، مركز طيفي، FFT، LPC وتقدير الصيغ، رنّان Klatt، علامات الطبقة، PSOLA، تقطيع على الصمت
src/wav.mjs         قراءة وكتابة WAV وإعادة العيّنة
src/mode.mjs        كشف فصحى/سعودية
cli.mjs, build-web.mjs, web/template.html
```

## حالة التحقق

- اختبارات الوحدة تمرّ (انظر `npm test`).
- جولة اصطناعية: الكلمات الـ48 مركّبةً بالمركّب الصيغي بحدود أصوات معلومة، ثمّ تسجيلها كأنّها صوت متكلّم: خطأ حدود المحاذاة الوسيط 45 مللي ثانية، و90% دون 185 مللي ثانية؛ طبقة الصوت المقدَّرة تطابق المركّبة؛ التركيب بالوصل غطّى 100% من الأصوات بلا رجوع إلى المركّب.
- لم يُقَس بعد: الوضوح السمعي (WER بأذن بشرية أو بمفرّغ خارجي)، وأداء المحاذاة على تسجيل بشري حقيقي بضجيج غرفة. أوّل تسجيل حقيقي سيحدّد ضبط عتبات الصمت وأوزان المحاذاة.

## المخرجات الصوتية الحالية

`out/` بعد `demo`: جمل فصحى وسعودية بالمركّب الافتراضي. في وضع التسجيل تُعاد نبرة المتكلّم وطبقته وسرعته ووحداته الصوتية؛ ما لم يُسجَّل من أصوات يُركَّب بملفّه.
